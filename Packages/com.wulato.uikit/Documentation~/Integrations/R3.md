# R3 Session 绑定（可选）

UIKit 不要求业务采用 MVVM，也不提供第二套绑定引擎。简单界面可直接使用 uGUI；需要响应式状态时，导入 Package Manager 的 **R3 Session Binding** 示例，复用 R3 的 `ObserveOnMainThread`、`SubscribeToText`、`OnClickAsObservable`。

## 安装与启用

先单独安装官方 [R3 / R3.Unity 1.3.1](https://github.com/Cysharp/R3/tree/1.3.1) 及其 NuGet 依赖，按官方说明选择项目的安装方式。UIKit 不自动下载 SDK，不要求安装全局 NuGetForUnity。R3.Unity Git 包地址：

`https://github.com/Cysharp/R3.git?path=src/R3.Unity/Assets/R3.Unity#1.3.1`

导入示例后，为使用的构建目标增加 `WULATO_UIKIT_R3`。仅安装 SDK 不会启用 UIKit 示例；未安装 SDK 时保持该符号关闭。示例和示例测试由独立 asmdef 隔离，基础 Runtime 和 `package.json` 不增加 R3 依赖。

本任务在 Unity 2022.3.62f2 / .NET Standard 2.1 验证以下原生 DLL 组合：

| NuGet | 版本 | 选择的 TFM |
| --- | --- | --- |
| R3 | 1.3.1 | netstandard2.1 |
| Microsoft.Bcl.TimeProvider | 8.0.0 | netstandard2.0 |
| Microsoft.Bcl.AsyncInterfaces | 6.0.0 | netstandard2.1 |
| System.Threading.Channels | 8.0.0 | netstandard2.1 |
| System.Runtime.CompilerServices.Unsafe | 6.0.0 | netstandard2.0 |
| System.ComponentModel.Annotations | 5.0.0 | netstandard2.1 |

使用 Unity 自带的 .NET Standard 2.1 平台引用，包括 Tasks.Extensions shim，不额外放入私有同名 DLL。保留程序集引用/版本验证。其他 Unity、TFM、SDK 版本或已有依赖组合需自行验证，不能把这份手工隔离宿主清单当成全局安装器。

## 生命周期与线程

`CounterView.OnOpenAsync` 在每次打开时创建订阅，全部传入 `scope.Track`。缓存关闭、正常关闭、打开失败、取消和 Shutdown 都由已有 Session 结束路径统一解绑。业务调用方持有并释放 `CounterModel`；View 不释放 Model。不能用 `AddTo(this)` 或 `OnDestroy` 代替 Session 所有权，因为 CacheOne 的 GameObject 会跨 Session 存活。

通知先通过 `ObserveOnMainThread()` 调度，再用捕获的本次 `scope.IsCurrent` 过滤，最后调用原生 uGUI helper。不要在回调中读取可被下一次打开替换的“当前 Session”字段。按钮订阅同样归本次 scope 所有。示例不改 SDK，也不增加 UIKit 绑定包装 API。

`ObserveOnMainThread` 只保证 UI 侧投递线程，不让任意 Model 读改写天然线程安全。业务应自行串行化并发状态修改；示例测试使用受控的单次后台通知验证调度边界。

## 验证与回退

示例附带 PlayMode 测试程序集，可在启用 `UNITY_INCLUDE_TESTS` 的测试宿主运行 `r3_binding` 类别。九个用例覆盖真实 SDK 身份、CacheOne 重开、业务 Model 所有权、主线程投递、旧 Session 队列通知、关闭按钮、Shutdown、打开失败回滚和取消后的迟到清理。

仓库专项入口：`python3 Tools/Verification/run.py tests --editor 2022.3.62f2 --backend legacy --mode PlayMode --suite r3-binding --host-root <已授权隔离宿主根目录>`。显式专项缺少符号/示例/SDK时应失败，不以跳过计通过。runner 不自动安装 SDK。

撤回此示例可移除导入的示例并关闭符号；不用修改 UIKit 核心或业务模型。保留用户自行安装的 SDK。
