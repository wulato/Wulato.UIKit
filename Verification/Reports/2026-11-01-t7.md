## 实现与边界

- UGUI 新增 `UIInputDomain`、`UIInputArbiter`、`LegacyUIInputDriver` 和共享 `UIModalMask`。具体 EventSystem 只允许一个输入域及仲裁器；重复仲裁器登记失败不影响原登记和所有者。驱动必须显式传入，拒绝同 EventSystem 上同时启用其他输入模块。
- 仲裁按 Context 优先级、最近取得交互及 Session 次序选择；普通 Overlay 不能越过模态屏障，关闭栈顶恢复前一个 Modal 和有效焦点。锁按幂等租约持有；撤回转场候选仍保留原屏障，注销则释放其全部锁。只有显式更高优先级 Emergency 策略可以抢占，旧锁释放不能恢复已转移的焦点。
- 生产驱动复用 P1 已验证的门控策略：清理按压/拖拽、阻止 click/drop、撤销当前 Process 内缓存指针，等待相关 UI 控件回到中性，再接受新鲜边沿。共享 EventSystem 不因单个 Context 被锁而禁用。指针、拖拽、Cancel 分别跟踪，保持 Button → ScrollRect 的原生拖拽目标。临时门控组件跟随实例复用，避免 CacheOne 同帧关闭重开触及 Unity 延迟销毁对象。
- 生产仲裁器接入已有引擎登记协议；首次前台通知失败回滚打开，恢复前台失败终结会话，退出通知异常只汇入关闭错误。前台作用域失去资格时取消/释放，恢复时创建新作用域。Core 公共契约及生命周期实现未修改。
- 新建 `com.wulato.uikit.input-system` 0.1.0，数字依赖主包 0.1.0 和 Input System 1.17.0；只有 input 宿主安装并列入 testables。主包/Core 无 Input System 硬引用。适配包源码纳入原 runner 的规范路径、指纹及原始证据封存；不放宽锁、零匹配或必需用例检查。
- Builder/默认服务组装、真实 Build 重复仲裁器回滚及 Reload 配置验收仍归 T8。本次不提供导航、弹窗队列、移动端或 IL2CPP 发布验收。
