## 实现与边界

- UIContextBuilder 显式组装默认 Prefab/Resources 加载器、UniTask 调度器、布局屏障、无动画转场及错误接收器；协议依赖可替换。配置与注册表在 Build 时复制，Root 独占，实际输入模块和域归属同步校验；Input-only 宿主拒绝 Legacy 驱动。
- UIContextFacade 仅转发现有 UIContextEngine，不复制状态机。服务工厂按登记顺序创建，构建期间只能查询已创建服务；普通命令不可用。完成后服务集合冻结，工厂对象按引用身份管理、逆序释放，失败回滚不影响已有 Context。外部注入的依赖及共享仲裁器仍由宿主拥有。
- 服务工厂返回的 IUISessionLifecycleObserver 自动登记；Session 绑定、终结、租约释放和服务释放顺序由真实打开/Shutdown 用例验证。Root 销毁和主动 Shutdown 均清理 Context 所创建的服务与登记。
- 同一 EventSystem 的默认仲裁器冲突构建失败，保留首个 Context 的输入所有者；显式共享宿主仲裁器的 Context 可独立运行。实际 View 的打开、前台转移、恢复和重新打开提供正向控制。
- GetService/GetDiagnostics 拒绝工作线程访问；停止后服务查询拒绝，但最终快照仍可读。Off 级别保留基础状态而省略详细条目，原有不可变快照没有引入 Unity 对象或可操作租约。
- SubsystemRegistration 清理静态桥接，运行时宿主在真实退出时停止 Context；独立 Editor 验证保留活跃 Context、服务订阅和未释放输入锁直到退出，不靠清空计数通过。
- 没有新增依赖、修改包版本或 ProjectSettings，也没有实现 T9 的 Editor 绑定/生成、导航或未来业务模块。

实现位置调整：诊断继续由唯一引擎的 BuildDiagnostics 组装，facade 直接转发，复用已有 UIDiagnosticsSnapshot；未为文件清单新增重复的无状态 UIDiagnostics 包装类。若后续需要独立采样器，可再提取，不改变本次 GetDiagnostics 契约。

## 红阶段、失败处理与集中作者自审

- [初始红阶段](../../Artifacts/uikit/20261101T060353799931-tests-b2dc99)：缺失 UIContextBuilder 导致编译失败，不将其描述为行为断言失败。首次沙箱启动停在授权连接，后续在获准的沙箱外执行指定编辑器。
- EditMode 的 EventSystem/输入模块不会自动经历运行时启用生命周期。初次修复触发 ShouldRunBehaviour，第二轮仍因 EventSystem 未登记失败，按 AGENTS.md 停止并保留现场。用户明确批准追加一轮后，测试专用夹具显式登记/注销 EventSystem 并初始化模块、配置 Overlay，12/12 通过；随后扩展为匹配宿主实际后端的夹具。没有屏蔽日志、放宽生产断言或删掉生命周期要求；真实 Root 销毁断言位于 PlayMode。
- [集中审查三项红阶段](../../Artifacts/uikit/20261101T061623422881-tests-36e373)：值相等但引用不同的工厂服务会漏释放；错误 Layer 会留下部分生成层级；工作线程能查询服务。分别改为引用身份管理、创建前完整校验及同步线程检查，全部纳入最终绿阶段。
- [Input-only 错误驱动红阶段](../../Artifacts/uikit/20261101T061734067753-tests-c5a355)：Legacy 驱动曾能构建成功，已同步拒绝；正向路径使用实际 Input System 适配驱动。
