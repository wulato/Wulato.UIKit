- 集中作者自审按用户规则未启动子代理。只改本任务文件，未手改生成工程、用户根 manifest/lock/ProjectSettings；保留原有非本任务修改。Unity .meta/GUID 保留，新资产补齐 .meta。

## 失败、误判与修正记录

1. **撤回原“缺少移动模块”判断。** 两个编辑器的 AndroidPlayer/iOSSupport 实际在与 Unity.app 同级的 PlaybackEngines；脚本误查 bundle 内部。已补两种布局回归，最终真实平台构建与设备运行通过。早期 BLOCKED 不是有效模块缺失证据，详见 [历史报告](../../Artifacts/uikit/t11-history/report-before-final.md)。
2. UPM 本地 Git URL 增加明确的 git+file 协议；聚合报告改用 matrix-report.json，避免误入严格测试注册命名空间。原聚合文件字节保留并记录重命名哈希，未删除失败或放宽注册检查。
3. Android 外部报告目录的 run-as 清理权限失败，改用 adb shell 正常外部存储访问并补回归；首次 Input System 新应用被手机拒绝安装，用户允许后重试成功。所有失败尝试已归档在相应构建目录，未将旧界面的人工反馈算作该组合通过。
4. 移动夹具 ViewA 为 UIView<int>，原先错误地传 None；实际设备捕获 InvalidRequest 后修正 int 参数，并增加构建前 Accepts 校验。
5. 用户报告关闭后持续闪烁：smoke 场景没有摄像机清屏；补固定背景摄像机及完成提示。用户再次实际触摸后确认 PASS 7/7、画面稳定，最终两平台全组合通过。
6. Xcode26.0.1 首次在 provisioning 阶段 SIGSEGV；独立 generic 复验明确报个人账号登录被拒绝、无匹配 Development Profile。用户恢复账号后，四项原始签名构建与真机测试均通过，未改用公司证书或免验签名。崩溃与失败原始数据保留在归档和 [t11-environment](../../Artifacts/uikit/t11-environment)。
