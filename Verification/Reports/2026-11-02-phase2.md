## 交付内容

- 核心与 Input System 适配升级 0.2.0；Navigation、Presentation、Dialogs、Popup Queue 四个可选 UPM 包各为 0.1.0，显式依赖核心 0.2.0。保留旧事务接口，新增页面事务能力、Context lifetime 和不可变注册快照。
- 导航在核心 FIFO 事务中完成成对动画、受控 Prepare/Commit/Rollback、描述式历史与 Push/Back；提交前回滚，提交后取消不撤销已提交状态。动画保留输入锁，Modal 屏障和异常隔离生效。
- Presenter 按 Session 创建、绑定、释放，支持工厂返回 null；部分绑定与清理失败保留错误，外部 Model 所有权不转移。
- Dialogs 显式请求注册和 responder；取消覆盖完整等待期，清理后抛 OperationCanceledException；终结意图与打开/关闭屏障分离，保留 UICompletion 错误。
- Popup Queue 使用描述式请求，提供优先级/FIFO、显示期去重、多暂停租约和共享 StopAsync；QueueStopped 与 ContextStopped 分开，等待 Closed 后推进。
- 组合样例包含 Home/Settings、确认对话、奖励队列及 Presenter；附各包接入文档、迁移说明、编译探针和扩展专项。CI 路径过滤及证据身份支持 phase2，默认 phase1 兼容，未启用远端 CI。

主要代码位于 `Packages/com.wulato.uikit/Runtime/Core/Transactions`、`Runtime/UGUI` 和四个扩展包；验证接入位于 `Tools/Verification`、`.github/workflows/uikit-*`、`Verification/Packages`。根 ProjectSettings 与根 packages-lock 的既有修改保留，未改写用户工作区或暂存内容。
