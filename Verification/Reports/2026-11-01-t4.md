## 交付

- `PrefabUIViewLoader` 与 `ResourcesUIViewLoader` 实现 T2 加载协议；Resources 默认加载器同时分派显式 Prefab 描述。必须直接在非激活 AnimationRoot 下以 `worldPositionStays=false` 实例化，不另造包装。拒绝活跃父级、非 activeSelf Prefab、缺少唯一启用 UIView 或 RectTransform 的根。
- `UIViewLease` 幂等持有并释放克隆；失败交付前清理部分实例。Resources 共享 Prefab 由 Unity 缓存，租约保留资源引用并释放自己的克隆，不调用不适用于 GameObject Prefab 的 UnloadAsset，也不全局触发 UnloadUnusedAssets。
- `UIRoot` 提供 Overlay／Screen Space Camera、默认逻辑层 Canvas/GraphicRaycaster 和可选 authored SafeArea 挂载。World Space、缺少相机的 Camera 配置被拒绝。生产 Builder 接入仍归 T8。
- `UIViewHostFactory` 创建独立非激活 staging/cache 父级；`UIViewHost` 实现 `Shell → AnimationRoot → PrefabRoot`，包装 stretch、零 offset、居中 pivot、单位缩放和旋转，作者 View 的 anchors/pivot/sizeDelta/anchoredPosition/scale 保持。两层包装均 `ignoreLayout=true`，不参与父级 LayoutGroup。
- Shell 的 CanvasGroup 独立承担隐藏/交互门控。配置检查拒绝未登记的 overrideSorting Canvas 和 ignoreParentGroups；动态 Preparing、OnEnable、OnOpen/Start 内容在门控、布局和帧/渲染边界复核，非法 Shell 同步停用并保存失败原因。`UIViewGateGuard` 使用可复用组件列表，不每帧分配数组。
- `UILayoutReady` 严格等待下一次 Update，然后 `Canvas.ForceUpdateCanvases()`，没有额外固定帧或重复 ForceRebuild。布局结果在同一帧交给进入步骤；OnOpen 内的 scope.WaitLayoutAsync 直接执行，不重新排队。
- Core 正常和迟到释放路径均先 DetachView，再 lease.Dispose，最后销毁空包装。实际测试在租约释放时核对 View 已分离、包装仍存活。
- 补齐包内 CHANGELOG、序列化测试 Prefab、Editor-only 夹具生成器和四宿主必需用例矩阵。现有 Runtime asmdef 引用已符合 §3.2，因此保持，不为满足文件清单而添加多余依赖；PlayMode 测试增加实际 Loading/UGUI/UI 引用。

## 初始化、几何和布局证据

最终 trace 保存实例 ID、OnCreate 时 Awake 状态与序列化引用、实际/对照 rect、pivot、布局/进入帧、内容尺寸、实际射线命中数和 detach/release 顺序。

- `InactiveLoad_DoesNotRunAwake`：加载后 activeSelf=true、activeInHierarchy=false、Awake 未执行且序列化引用存在；调用 OnCreate 后才激活，记录同实例 create→awake→enable。
- `RealEngine_CreatePrecedesAwake_AndDetachPrecedesRelease`：真实引擎与默认 loader/host/layout，记录 create→awake→enable→open→dispose→lease-release；释放次数 1，无活跃租约遗留。
- `NonStretchPrefab_WrapperPreservesRect` 及 Overlay/Camera × 有无 SafeArea 四组：与直接挂到同一目标层的独立对照实例比较作者属性和四个世界角点，容差 0.02；特殊 pivot 为 `(0.23, 0.81)`。
- `CacheParentResize_UsesCurrentLayerRect`：同一 Host 移入 `(17,29)` 缓存父级，改变当前 SafeArea 尺寸后重新挂回，与当前层直接实例化对照相等；原实例不重复 OnCreate/Awake。此项直接测试 Host 重新挂载，不创建 CacheOne 策略。
- `ContentSizeFitterAndLayoutGroup_AreReadyAfterOneUpdate`：实际 VerticalLayoutGroup、LayoutElement 和 ContentSizeFitter，在下一帧得到 `(185,114)`；进入步骤同帧观察到该尺寸。另验 OnOpen 内布局等待、取消和 timeScale=0。
- `HiddenActiveView_IsNotRaycastable_VisibleOwnerIs`：真实 GraphicRaycaster 隐藏命中 0、可见且有资格的正向控制命中 1，再隐藏后不命中，未禁用接收对象来假通过。
- `LayerLayoutGroup_DoesNotDriveWrappers`：目标层存在 VerticalLayoutGroup 时，包装仍保持 stretch，View 几何与独立对照一致。
- 动态旁路：序列化非法 Canvas、OnEnable 实际设置成功的 Canvas、OnOpen 动态子节点、异步 OnOpen 跨帧和打开后门控变更均有回归；后者先验证真实可命中，再验证非法配置被拒绝且实际射线消失。
